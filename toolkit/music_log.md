# Журнал музыки рилсов

Правило (STYLE.md, с 2026-11-12): пресет нового рилса не повторяет **3 предыдущих** строки этого журнала. Пресеты — `toolkit/lib/audio.py`, задаются в рилсе через `window.MUSIC = {preset: "..."}` (и `window.BPM` под темп пресета).

| Пресет | Темп | Характер |
|---|---|---|
| `lofi84` | 84 | lo-fi: пыльный свинговый бит, Rhodes-аккорды, виниловый треск |
| `house122` | 122 | минимал-хаус: прямая бочка, офбит-хэты, органные стабы |
| `garage132` | 132 | UK garage 2-step: ломаная бочка, шаффл, рубленые плаки, саб с глайдом |
| `boombap90` | 90 | бум-бэп: тяжёлые бочка и снейр, пиано-чоп в миноре |
| `ambient70` | 70 | эмбиент без ударных: фетровое пиано-арпеджио, пэд, длинный хвост |
| `office110` | 110 | «офисный» груув: ударные из звуков бюро (штамп, машинка, бумага), маримба, колокольчик |
| `asmr` | — | без музыки: тон комнаты, звучат только эффекты бюро (раз в 4–5 рилсов) |
| `classic` | 120 | старый бит (r1–r8), больше не используем |

## История

| Дата выхода | Рилс | Пресет |
|---|---|---|
| 2026-11-05 … 11-10 | r1–r8 (старый стиль) | classic |
| 2026-11-13 | r9 «Пиши ДЕМО» (новый стиль) | office110 |
